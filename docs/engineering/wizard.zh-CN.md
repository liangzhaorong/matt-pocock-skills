## 它做什么

`wizard` 生成一个交互式 bash 脚本，带一个人一步步走完一套手动流程：接通第三方服务、跑一次一次性迁移、把一个项目从状态 A 挪到状态 B。它打开每个 URL，说明点什么、复制什么，捕获回来的东西，并把它写进 `.env` 文件和 GitHub Actions 密钥。

[智能体](https://www.aihero.dev/ai-coding-dictionary/agent)写脚本，从不运行脚本。运行的是你，在你自己的机器上。一个向导是一个程序，不是一张说明清单。脚本按顺序执行每一步，并保留你输入的值。你负责的是点击、粘贴和按回车。

## 何时该用它

你可以输入 `/wizard`，智能体也可以自己取用它。当它撞上一步非你不可的操作（一把它造不出的密钥、一个它点不了的看板），它会给你造一个向导，而不是把说明写进聊天里被滚走。

当下一件拦住你的事是一趟看板之旅时，找它：

| 处境 | 向导做什么 |
| --- | --- |
| 一个新开发者要在应用能启动前配好六个服务 | 按顺序打开每个控制台，捕获密钥，写进 `.env` 和 CI |
| 一次一次性迁移需要按特定顺序拨开关 | 把不可逆的步骤排在确认闸门后面 |
| 一个项目要一次性从状态 A 挪到状态 B | 走完这段过渡，并报告它办不到的部分 |
| 你正要把这些步骤写进 README | 改写一个可执行的版本，某步过时时它会显眼地失败 |

别用它来*决定*构建什么；那要用 [grill-with-docs](https://aihero.dev/skills-grill-with-docs) 和 [to-spec](https://aihero.dev/skills-to-spec)。

## 前置条件

生成一个不需要任何前置。它写出的向导跑在 bash 上，当某个阶段要设置 GitHub 密钥或变量时用 `gh`。如果 `gh` 缺失或未认证，运行不会失败。那个阶段显示一条警告，收尾摘要会告诉你哪些要手工设置。

## 阶段

一个**阶段（stage）**是一块屏幕上的一个专注任务。脚本在阶段之间清空终端，所以一个超出屏幕的阶段会丢掉滚走的部分。你按依赖顺序编排阶段，并设置 `TOTAL_STAGES`，它驱动进度显示。

[技能](https://www.aihero.dev/ai-coding-dictionary/skill)在写任何脚本之前先圈定流程范围。它读仓库而不是冷不丁发问：`.env*`、`docker-compose*`、框架配置，以及 `.github/workflows/` 里每一处 `secrets.*` / `vars.*` 引用。每一处引用都是向导必须产出的一个值。然后它把排好序的阶段清单给你确认。只有你确认之后，它才把每个阶段映射成人要走的准确路径（“Dashboard → Developers → API keys → Reveal test key → 复制”）。在它不知道当前 UI 长什么样的地方，它问你或查文档，而不是发明点击。

对每个捕获的值，范围圈定决定它去哪：

| 目的地 | 什么时候 |
| --- | --- |
| 只进 `.env` | 本地开发需要，CI 不需要 |
| GitHub 密钥 | CI 要读它，且它敏感 |
| GitHub 变量 | CI 要读它，且它公开 |
| `.env` 和密钥都进 | 本地开发和 CI 都需要 |
| 哪都不去 | 该阶段是纯动作：拨一个开关、升一个套餐 |

## 模板已经解决了 UX

[模板](https://github.com/mattpocock/skills/blob/main/skills/engineering/wizard/template.sh)随附整套体验：带剩余时间的进度、确认闸门、跨平台打开 URL（含 WSL）、密钥的隐藏输入、幂等的 `.env` 写入、`gh secret` / `gh variable` 写入，以及一份列出它不得不跳过的一切的收尾摘要。`STAGES` 标记以上的所有东西是一个固定的库，每个向导一模一样，从不手改。因为这个库从不变化，每个向导的行为都一样。每个向导仅有的活是圈定流程范围和编排阶段。

写向导的智能体从不端到端运行它，因为脚本要开浏览器、等人输入。智能体改做静态检查：`bash -n`、有 `shellcheck` 就跑，再核一遍每个值都落在范围圈定所说的地方、每个 `set_secret` 的名字都对得上 CI 里一处真实的 `secrets.*` 引用。所以第一次运行是你的，那一次运行就是测试。

## 默认一次性

| 你手上是什么 | 脚本怎么处置 |
| --- | --- |
| 一次一次性迁移、一套个人配置、一段你不会再重复的过渡 | 存到 scratch 或 `scripts/` 路径，跑完删掉 |
| 一条仓库里的下一个人也需要的配置路径 | 提交它并从 README 链过去，这样他们跑脚本，而不是再问一遍智能体 |

## 常见问题

**我的 API 密钥会进模型的上下文吗？**

不会。智能体写脚本，不运行脚本。你自己跑脚本，它用隐藏的终端输入捕获密钥，直接写进 `.env` 或 `gh secret`。向导是一个 CLI，模型没有连着它。这只对向导在运行时捕获的值成立。如果你在圈定流程范围时把密钥贴进聊天，它就和其他任何贴进来的文本一样进了[上下文](https://www.aihero.dev/ai-coding-dictionary/context)。

**我能回退改一个打错的值吗？**

运行中不能。没有后退键。阶段只向前跑，第 3 阶段答错就意味着 Ctrl-C 重来。重跑很便宜，因为已写进 `.env` 的值会作为默认值回显，你一路回车穿过答对的阶段，只重打错的那一个。发布当周就有用户要这个功能，仍未关闭：“很喜欢！不过，有没有办法回去改已经输入的内容？”

**它知道我已经配好了什么吗？**

部分知道，且比发布时的反应所以以为的少。它先读仓库再发问（你的 `.env` 文件、`docker-compose`、框架配置、CI 里的 `secrets.*` 引用），所以它圈定的是缺的值，而不是像 README 那样从零开始。它不做的是检查第三方服务。如果某个密钥已在你的 `.env` 里，向导回显它，回车即保留；如果你已经建了 Stripe 账户但从没存下密钥，向导还是会把你派去控制台拿它。

**它在工作流里处于什么位置，在拷问和规格之后吗？**

没有特别的位置。它是独立件，不是链条一步。常见的猜测是 `/grill-with-docs → /to-spec → /wizard`，这个顺序也没问题，但它的触发条件是“一套手动流程出现了”，这可以发生在任何时点：开工前、构建中、交付很久之后。它还能当勘察工具用。圈定范围会在你承诺这项工作之前，找出它的隐藏前置，比如那三把你没想到的 API 密钥。

**它在 Claude Code 之外能用吗？**

脚本能。它是纯 bash，无论哪个 [harness](https://www.aihero.dev/ai-coding-dictionary/harness) 生成的，跑起来都一样。技能本身是模型可调用的，所以哪儿都列着它：在 Claude Code 里输 `/wizard`，在 Codex 里输 `$wizard`，或者直接描述你卡住的配置。模型可调用还让它躲开了 [#693](https://github.com/mattpocock/skills/issues/693)：Claude 的桌面和网页应用会把*用户调用*的技能从[模型](https://www.aihero.dev/ai-coding-dictionary/model)的清单里丢掉，并报告它们未安装。

**它以前不是用户调用的吗？**

是的。现在是模型可调用的，所以撞上非你不可的一步时，智能体会不打招呼地取用它。以前能用的没一样失效。模型调用让智能体和你一样能唤起技能，所以 `/wizard` 行为照旧。这个改动修好了一种失败。以前，一个在构建中途撞上凭据墙的智能体会往聊天里倒六条编号步骤让你照做。现在它写一个向导。

**它以前在 `in-progress/` 里，现在在哪？**

v1.2 起在 `engineering/`。它从 beta 桶毕业了，现在随插件发布，和其他已推广技能一起到达，不再需要单独安装。毕业时行为没有变。

## 有这些表现就说明它在生效

- 在任何脚本存在之前，你先看到一份排好序的阶段清单和每个阶段产出的值，并被要求确认。
- 每个 URL 都在询问该页的值之前打开。绝不会让你粘贴还没被派去取的东西。
- 密钥盲打。没有敏感的东西回显进你的回滚缓冲。
- 每个阶段装得进一屏。你还需要的东西没有被滚走。
- Ctrl-C 重跑能从你停下的地方接上，已保存的值作为默认值回显。
- 最后一屏列出它写了什么，并单列出它办不到、要你手工收尾的部分。

## 它的位置

`wizard` 是一个随取随用的独立件，停在自动化到头、必须由人来点击的那条线上。它最近的邻居是 [setup-matt-pocock-skills](https://aihero.dev/skills-setup-matt-pocock-skills)，因为两者都为把一个仓库弄到能用而存在。那一个配置这套技能，`wizard` 为其余一切生成配置路径。它也与 [implement](https://aihero.dev/skills-implement) 搭档：当一次构建交付了一个需要凭据或手动切换的特性时，向导罩住只有人能做的那几步。拿不准当下该用哪个技能时，[ask-matt](https://aihero.dev/skills-ask-matt) 为你路由。
