---
name: handoff
description: 把当前对话压缩成一份交接文档，供另一个代理接手。
argument-hint: "下一个会话将用来做什么？"
disable-model-invocation: true
---

撰写一份交接文档，总结当前对话，让一个全新的代理能够继续这项工作。保存到用户操作系统的临时目录（`$TMPDIR`，没有则 `/tmp`；Windows 上是 `%TEMP%`），而不是当前工作区。

在文档中加入一个"建议技能"部分，点名下一个代理应该对哪些技能调用 Skill 工具。

不要重复其他工件（规格、计划、ADR、issue、提交、diff）中已记录的内容，改为按路径或 URL 引用它们。

对任何敏感信息进行脱敏，例如 API 密钥、密码或个人可识别信息。

如果用户传入了参数，把它当作对下一个会话工作重点的描述，并据此定制这份文档。
