# 学习记录格式

学习记录存放在 `./learning-records/`，使用递增编号：`0001-slug.md`、`0002-slug.md` 等。目录惰性创建：只在写第一条记录时才创建。

它们是教学界对应 ADR 的东西：记录不明显的教训、关键洞见，以及将主导未来会话的既有知识声明。它们用于计算最近发展区。

## 模板

```md
# {所学或所确立内容的简短标题}

{1-3 句话：学到了什么（或确立了什么既有知识），以及它为什么影响未来的会话。}
```

这就是全部格式。一条学习记录可以只有一个段落。价值在于记录*这*一点现已可知、以及*为什么*它改变了接下来教什么，而不在于填满各个小节。

## 可选小节

只在真正增值时才包含它们。大多数记录用不上。

- **Status（状态）frontmatter**（`active | superseded by LR-NNNN`）：当早先的理解后来被发现有误并被取代时有用。
- **Evidence（证据）**：用户如何展示了该理解（答对的一个问题、完成的一个练习、引用的过往经验）。当某个论断日后可能被重新审视时有用。
- **Implications（影响）**：它为未来会话解锁或排除了什么。在不显然时值得记录。

## 编号

扫描 `./learning-records/`，找到现有最大编号，加一。

## 何时写学习记录

当以下任一为真时写一条：

1. **用户对某件不简单的事展示了真正的理解**：不只是接触过，而是有能正确使用该概念的证据。这为接下来教什么设定了新的下限。
2. **用户透露了既有知识**："我已经会 X 了。"记录下来，未来会话就不会重教。还要记录声称的*深度*。
3. **一个误解被纠正**：用户此前相信某件错的东西，现在明白了为什么。这类记录价值很高：它们预示相关主题未来的绊脚石。
4. **使命因学习而转变**：用户发现自己在乎的其实与原以为的不同。交叉链接到 [[MISSION.md]] 并更新它。

### 什么*不*算

- 仅仅讲过的内容。讲过不等于学会。等待证据。
- 已在 [[GLOSSARY.md]] 中作为术语定义简洁记录的东西。不要重复。
- 逐会话的活动日志。学习记录不是日记：它们是决策级别的洞见。

## 取代

当后来的记录与早先的矛盾（用户的理解加深或被纠正）时，把旧记录标记为 `Status: superseded by LR-NNNN`，而不是删除它。理解如何演变的历史，本身就是有用的信号。
