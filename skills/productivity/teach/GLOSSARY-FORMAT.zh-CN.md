# GLOSSARY.md 格式

`GLOSSARY.md` 是本教学工作区的规范语言。所有讲解、练习和学习记录都应遵守它的术语。构建它本身就是学习的一部分：把一个概念压缩成一段严密的定义，正是用户理解了它的证据。

## 结构

```md
# {主题}词汇表

{一两句话，描述本词汇表覆盖的主题。}

## 术语

**肌肉肥大（Hypertrophy）**：
跨多次训练由机械张力和代谢压力驱动的肌肉增长。
_避免_：Bulking（增重增肌）、练大只

**渐进超负荷（Progressive overload）**：
随时间通过负荷、容量或强度，系统地增加对肌肉的要求。
_避免_：加把劲、升级

**RPE（自觉用力程度，Rate of Perceived Exertion）**：
对一组训练吃力程度的 1-10 自评，10 表示力竭，8 表示还能再做两次。
_避免_：费力评分、强度评级
```

## 规则

- **只在用户理解了一个术语后才收录它。** 词汇表是压缩知识的记录，不是用户拿来学习的词典。如果用户刚接触某个概念，等到他们能正确使用它，再把它提升进来。
- **要有主见。** 当同一个概念存在多个说法时，选出最好的那个，把其余列为应避免的别名。语言就是这样压缩的。
- **定义要严密。** 一两句话。定义这个术语*是*什么，而不是它做什么或怎么做。
- **在定义中使用词汇表自己的术语。** 一旦某个术语进入词汇表，就在所有地方优先使用它，包括其他定义的内部。这正是让复杂术语日后更易掌握的原因。
- **在出现自然聚类时用子标题分组**（例如 `## Anatomy（解剖）`、`## Programming（训练编排）`）。术语本身内聚时，平铺列表也可以。
- **显式标注歧义。** 如果某个术语在更大的领域里被用得很宽泛，注明本工作区的裁决："本工作区中，'set' 一律指正式组；热身组单独记录。"
- **随理解加深而修订。** 用户第一周写下的定义，到第六周可能就错了。就地更新；不要留下过期条目。
