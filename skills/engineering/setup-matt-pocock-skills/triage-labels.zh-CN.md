# 分诊标签

这些技能使用五种规范分诊角色来表达状态。本文件将这些角色映射为当前仓库的问题跟踪系统实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们的问题跟踪系统中的标签 | 含义 |
| -------------------------- | -------------------------- | ---------------------------------------- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 说明完整，已准备好交给无人值守的智能体处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个角色时（例如“应用可交给无人值守智能体处理的分诊标签”），使用本表对应的标签字符串。

编辑“我们的问题跟踪系统中的标签”一列，使其与你实际使用的词汇一致。
