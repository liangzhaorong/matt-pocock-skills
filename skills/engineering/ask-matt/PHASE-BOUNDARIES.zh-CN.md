# 阶段边界

**阶段**（phase）是会话内的一块工作：拷问、实现、QA。这个定义故意保持模糊：当你觉得*“好，这块做完了”*的时候，一个阶段就结束了。

**阶段边界**（phase boundary）是两个阶段之间的间隙，也是这个决策唯一所属的地方。阶段中途没有决策要做：要么继续，要么把剩下的工作拆给子代理。在阶段中途做 compact 会让代理丢掉主线。

## 五个选项

| 选项           | 作用                                                               |
| -------------- | ------------------------------------------------------------------ |
| **继续**（Continue） | 留在本会话中。完全没有上下文切换。                                     |
| **`/clear`**   | 清空上下文窗口，从零开始。                                           |
| **`/handoff`** | 写出一份可携带的 markdown 文件，用它随时随地播种一个会话。              |
| **子代理**（Subagent） | 把任务送进它自己的上下文窗口，收回一份报告。                          |
| **`/compact`** | 压缩当前上下文，用摘要播种一个新会话。                                 |

## 决策树

在边界处自上而下地过这棵树。第一个**“是”**获胜。

**1. 这个会话还能继续吗？** 两件事会让答案为“是”：下一个阶段需要把当前阶段当作**一手来源**（primary source），或者你剩下的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k token）还够装下下一个阶段。拷问 → 实现是标准的“是”：实现想要的是一字不差的推理过程，而不是它的摘要。继续不花成本、也不丢东西，所以先试着排除“继续”，再考虑其他任何选项。

**2. 上下文对接下来要做的事无关吗？** 这个会话里的一切（探索、决策、死胡同）都可丢弃吗？如果可以，**`/clear`**。它是棋盘上最便宜的一步棋：不花时间，并归还整个窗口。`/clear` 也不是终局：旧会话仍然可以恢复。

把这个判断搞错的代价是单向的。清掉一个*相关的*上下文，你就失去了所构建之物背后的**为什么**，而且把 diff 翻来覆去读多少遍，也换不回它。

**3. 需要交接吗？** `/handoff` 的适用面很窄。只有当你处在以下情形时才需要它：

- 换到一个**新的 harness**（Claude → Codex），
- 搬到一个**新目录**或新仓库，
- 把工作交给一位**同事**，
- 或在**阶段中途**分出一条支线任务，同时不打断手头的事。

这份清单就是全部条款。`/handoff` 换来的是**可携带性**：一个能到处走的文件。如果没有东西要带走，你就不需要它。

**4. 这个任务能挂机完成吗？** 它的范围是否收得足够紧，能在你人不在键盘前、无需随时掌舵的情况下运行？那就把它发给一个**子代理**，让当前会话原封不动。自动化评审是标准情形：代理读 diff、做汇报，期间不需要你。

**5. 否则，`/compact`。** 上下文相关、harness 不变、目录不变，而你又必须留在循环里：这就是决策树的落点，而且它经常落在这里。给它传一条指令（`/compact we're going to QA this area`），好让摘要保留下一个阶段所需要的东西。

`/compact` 是**默认项，而不是第一个伸手的选择**。它位于最底层，因为排在它上面的四个问题都更便宜或更精确。一上来就从这里开始的失败模式是：新会话对某个被摘要压平的决策，自信满满地搞错。

## 一手来源与二手来源

除**继续**外的每一步都会把**一手来源**（primary source）变成**二手来源**（secondary source）：实际发生的会话，被它的摘要所取代。这笔交易永远是同一个形状：

| 来源                              | 信息量 | 噪音 | 回旋余地 |
| --------------------------------- | ------ | ---- | -------- |
| 一手（继续）                       | 完整   | 多   | 少       |
| 二手（`/compact`、`/handoff`）      | 有损   | 少   | 多       |

这正是问题 1 排在最前面的原因。只有当“继续”的代价超过它省下的收益时，你才付出这份有损的代价。

## 这些都是主观取舍

这些问题不是客观的：每一题里都有品味，同一个边界在两天里可以走向两条不同的路。价值在于**按顺序**提问，在边界处问，而不是在工作的中途问。
