---
name: claude-handoff
description: 把当前对话交给一个全新的后台代理，由它立即接手工作。
argument-hint: "下一个会话将用来做什么？"
disable-model-invocation: true
---

写一份当前对话的交接摘要，让一个全新的代理能够继续这项工作。把它保存到用户操作系统的临时目录，然后启动一个以它为提示词的后台代理：`claude --bg --name "<描述性名称>" -- "$(cat <摘要文件>)"`。传文件而不是内联内容，是为了避免 shell 去执行摘要里的反引号或展开 `$`。它在当前工作目录启动并立即返回；用户用 `claude agents` 管理它。

始终传带描述性名称的 `-n`/`--name`（例如 `--name "Fix login bug"`）；它设置任务列表、会话选择器和终端标题里显示的名称。

在摘要中加入一个"建议技能"部分，点名下一个代理应该对哪些技能调用 Skill 工具。

不要重复其他工件（规格、计划、ADR、issue、提交、diff）中已记录的内容。改为按路径或 URL 引用它们。

对任何敏感信息进行脱敏，例如 API 密钥、密码或个人可识别信息，因为摘要会成为该代理的提示词。

如果用户传入了参数，把它当作对下一个会话工作重点的描述，并据此定制摘要。
